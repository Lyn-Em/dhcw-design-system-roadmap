Design system

Design System roadmap

See what we’re working on now and what we plan to work on next.

We update the roadmap as we learn more from research, feedback and teams using the Design System. Work further into the future is more likely to change.

Now Next Later

Now

Work currently in progress.

Prototyping

Develop the prototyping kit

We’re developing a prototyping kit to help teams create and test realistic prototypes using the DHCW Design System.

Prototyping

Create prototyping kit website

We’re creating step-by-step guidance to help people set up their computer, create and work on prototypes, and get help when they need it.

Welsh language

Plan the Welsh Design System

We’re working with Welsh language colleagues to plan how the Design System will work in Welsh. This includes translating the guidance and identifying components that need Welsh language co-design or testing.

Research and testing

Test the Design System Beta

We’re gathering feedback from teams using the Design System to understand what works well and what needs to be improved. We’ll use this evidence to help prioritise work during beta.

Next

Work we plan to start next.

Components and patterns

Add patterns to the Design System

We’ll research common user needs across NHS Wales services and develop patterns where a shared approach could help teams create more consistent services.

Components and patterns

Bring existing components into the Design System

We’ll work with teams that have developed their own UI components to identify things that could be reused across NHS Wales. We’ll review and test them before adding them to the Design System.

Welsh language

Review components for Welsh

We’ll co-design the key components that need careful Welsh language consideration with the Welsh language team. This includes instances where translating the content could affect how the component works.

Welsh language

Translate the Design System

We’ll work with the Welsh language team to translate the Design System guidance and website content into Welsh. Their expertise will help us adapt content where a direct translation would not work well.

Later

Work we expect to do in the future.

Welsh language

Make the Design System available in Welsh

We plan to make the Design System available in Welsh, with translated guidance and components that have been designed and tested to work in both languages.
