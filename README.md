DHCW Design System roadmap
The public roadmap for the DHCW Design System.

The roadmap shows what the Design System team is working on now and what we expect to work on next.

Updating the roadmap
Roadmap items are contained in index.html.

Items are grouped into:

Now
Next
Later
To update the roadmap, edit the relevant item in index.html, save your changes, then commit and push them to GitHub.

Running locally
No installation or build process is required.

Open index.html in a web browser to view the roadmap locally.
